O presente código foi desenvolvido com a finalidade de elaborar um relatório técnico contendo:

* Cálculo de intervalo de confiança para proporções de duas variáveis qualitativas;
* Teste de hipótese para proporção de variáveis categóricas;
* Teste de hipótese para média de variáveis numéricas.

Todos os procedimentos foram implementados utilizando **Python** e a biblioteca **Pandas**. O código encontra-se devidamente comentado, 
apresentando passo a passo cada etapa do desenvolvimento, incluindo a formulação das hipóteses estatísticas e o objetivo de cada teste aplicado.
